一、通用水果验收总则包装验收 （1）外包装干净无泥水、无腐烂汁水渗漏、无发霉异味；纸箱 / 泡沫箱无破损、无泡水软化；网套完整包裹果身，无挤压破皮。（2）分级包装需与标注规格一致，混级、大小混乱拒收；散装筐装底层垫防护垫，无底层压烂。成熟度标准 （1）应季鲜果：七八成熟最佳，耐储运、货架周期长；过生酸涩难售卖，过熟发软易腐直接拒收。（2）催熟类（香蕉、芒果、榴莲、牛油果）：到货为硬熟半成品，无大面积黑斑、流汁。卫生与农残 （1）果面无明显农药斑点、无白色药残粉；无虫卵、活虫、虫洞连片；无泥土大量附着。（2）进口水果附带报关单、检疫证明；国产批量鲜果可索要农残检测批次报告，无凭证暂缓收货。重量验收 净果重扣除包装重量，误差≤±1%；缺斤短两超 2% 直接扣重或拒收。温度验收 （1）冷鲜水果（草莓、蓝莓、葡萄、杨梅）到货车厢温度 0–4℃，果身温热、出水软烂拒收；（2）常温果（苹果、橙子、哈密瓜）无发烫发酵手感。瑕疵通用判定 （1）单果损伤面积＜1cm²、单箱瑕疵果占比＜5%：折价收货。(2)单果腐烂、流汁、发霉、虫蛀穿孔、冻伤、碰伤软烂：整果剔除。(3)单箱瑕疵果＞10%：整批拒收。二、仁果类验收标准（苹果、梨、海棠果）1. 苹果（红富士、花牛、嘎啦等）外观：果形端正，色泽均匀；果面光洁无裂纹、无黑点病斑；无鸡爪纹连片。手感：果肉坚实有弹性，不发糠、不空心；果柄新鲜不干枯。拒收项：果心腐烂、大面积苦痘病、磕碰软烂、表皮发霉、内部褐变。2. 梨（秋月、雪梨、鸭梨、香梨）表皮细腻无黑斑、无锈斑连片；无裂果、无挤压凹陷。果肉紧实，切开无黑心、无蜂窝糠心；无发酵酒味。拒收：冻伤发黑、果肉软烂、果身渗水。三、柑橘类验收标准（橙子、沃柑、砂糖橘、柚子、柠檬）1. 砂糖橘 / 蜜橘 / 沃柑果皮橙红鲜亮，薄而有韧性；无干皮、无浮皮松软；果蒂青绿不干枯。无花皮、无油胞黑斑；无腐烂发酵味；无落地压烂果。拒收：果皮发霉、果肉脱水干柴、内部发酵流水。2. 脐橙 / 冰糖橙果身饱满，表皮光滑，无大疤痕；果脐无开裂腐烂；手感沉甸甸不空心。禁止大量青果混装，成熟度不足酸涩果占比过高拒收。3. 柚子（白心、红心蜜柚）表皮完整无磕碰裂口，油胞细密；果型端正，无伤痕，有重实感，轻拍声音厚实不空洞。切开验收：果肉颗粒饱满，无干瓣、无糖化腐烂、无苦味霉变。拒收：外皮发黑腐烂、果肉脱水纤维化、内部发霉。4. 柠檬果皮金黄光滑，无皱皮、无霉点；果身硬实，果味香浓，无软烂出水。四、热带水果验收标准（香蕉、芒果、榴莲、山竹、火龙果、菠萝、木瓜）1. 香蕉八成熟，金黄色，头尾略青，香气浓郁；手感坚挺不塌陷，无发酵酒味；禁止生青硬果大批量到货。通体发黑、果肉软烂、果柄发霉拒收。2. 芒果（台农、贵妃、小台芒）七八成熟，果皮有本品种底色，色泽鲜艳，果实饱满，气味芬芳，无黑斑；果肩坚实，仅果尖轻微发软为正常。拒收：流汁腐坏、果皮长白毛、果肉发酵发酸、虫洞穿孔。3. 山竹果壳紫黑有光泽，果蒂鲜绿；捏壳弹性可开合。验收抽检掰开：果肉雪白完整，无发黄、无黏糊、无黄浆、无虫蛆。拒收：果壳干硬打不开、果肉发黑腐烂、底部流黄汁。4. 火龙果（红心 / 白心）鳞片完整新鲜，无干枯发黄；果皮无大面积褐色腐烂斑块。果身有韧性，按压不塌陷；切开果肉无蜂窝水化、无酒味。5. 榴莲刺坚硬有弹性，果体完整，果味浓烈。果体开裂、果肉外露拒收。果肉奶黄紧实，无出水、无发酵酒味、果核不软烂。6. 菠萝 / 凤梨叶片青绿易拔除；果实坚挺，皮黄略带青色，果体有清香，果眼无发黑腐烂，无发酵酸臭味。切开果芯不发黑，果肉无水化软烂；黑心菠萝整箱拒收。五、浆果类（高损耗，全检重点：草莓、蓝莓、葡萄、杨梅、猕猴桃）1. 草莓果体鲜红坚实，颗粒不松软，有香气，颜色红不沾泥浆，蒂叶翠绿；无发白生果、无压烂出水、无白毛霉菌。盒底无积水渗水；碰伤、软烂果超过 3 颗 / 盒直接拒收。2. 蓝莓果粉完整均匀，果实深蓝不发灰；无瘪果、无霉变、无出水。盒内无烂果汁液粘连，果身不发软。3. 葡萄 / 提子果串完整不掉粒，果梗青绿不干枯，果蒂发青紧连果粒。颗粒紧实有弹性，皮色光亮无斑痕，无破皮流水、无灰霉白点；果箱底部无烂果积水。4. 猕猴桃（绿心 / 黄心）硬果到货，无局部软烂；表皮无大面积黑斑、无发酵酒味。通体发软、果心腐烂、表皮发霉直接拒收。5. 杨梅果粒紫红紧实，无出水软烂；无白色霉菌；禁止高温捂闷到货。六、瓜类验收标准（西瓜、哈密瓜、甜瓜、羊角蜜）西瓜：表皮纹路清晰，瓜蒂新鲜；拍打声音浑厚，无空洞闷响。无裂口、无腐烂斑块。切开抽检：果肉鲜红，无白筋、无籽腐、无酸味。拒收：熟过糖化、果肉渗水发糟、瓜皮发霉。哈密瓜：表皮坚硬有清香，无磕碰凹陷；脉络条斑清晰；果肉脆实，无水化、无发酵酒味。为褐色、鲜黄、黄绿或绿色。果脐软烂拒收。香瓜：瓜蒂翠绿、饱满、有韧性，果皮软硬适中，瓜脐处有清新的甜味。过软发黏拒收。羊角蜜：果柄呈浅褐色或者翠绿，表皮坚硬有清香，有细密绒毛，无磕碰凹陷，无霉斑；有酒精发酵味或霉味拒收。七、核果类（桃子、油桃、李子、杏子、樱桃）1. 桃 / 李子：果形端正完整，无破损，无斑痕，果体不软，绒毛 / 果皮干净；无裂口流胶、无虫眼、无黑斑腐烂；七八成熟，果肉紧实。过熟软烂、果心发黑拒收。2、油桃：果色金黄泛红，气味清香，大小均匀，果形完整，无破损，无斑痕，果体不软，无裂口流胶、无虫眼、无黑斑腐烂；七八成熟，果肉紧实。3、杏子：捎带绿色，无破损，无斑痕，果体不软，无虫眼、无黑斑腐烂；七八成熟，果肉紧实。4. 车厘子 / 樱桃果梗青绿，果实紫红硬实；色泽不晦暗，果身不熟软，无破皮流水、无褐变斑点、无霉点。低温到货，果身发热、软烂粘连整盒拒收。八、特殊小众水果简版验收标准牛油果：到货硬实，仅少量果肩轻微软；表皮无大面积黑斑、无果肉发黑。无花果：果身柔软但不流汁，无霉菌，当天到货当天售卖，烂果直接剔除。人参果：表皮奶白带紫纹，硬实不空心，无异味、无腐烂斑点。石榴：果皮光滑，色泽鲜艳，不开裂。果皮完整无裂口，籽粒饱满鲜红，内部无发霉干瓣。荔枝：果柄青绿，剪口新鲜。果皮龟裂片饱满凸起，手感坚实有弹性；有纯正清甜果香。果皮发软，皱皮干缩，压伤塌陷拒收。九、收货判定处理规则（落地执行）合格收货：瑕疵果占比＜5%，重量达标、成熟度适宜、无腐烂发霉，正常入库定价。折价收货：5%≤瑕疵果≤10%，现场拍照登记，按破损比例扣货款，做当日特价处理。整批拒收 腐烂、流汁、发霉、虫蛀果超 10%；果身高温发酵、带有浓烈酒味；缺斤短两严重、混级掺大量次果；冷鲜水果运输温控失效，全部软烂；无检疫 / 农残证明的进口、批量鲜果。抽检比例要求 浆果类（草莓、蓝莓、葡萄）：每箱必抽检，盒装 100% 目视检查；瓜类、榴莲、柚子：每批次随机切开 10% 抽检内部品质；苹果柑橘等耐储果：每 5 箱抽 1 箱开箱查验底层。
