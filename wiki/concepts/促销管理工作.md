# 促销管理工作

## 促销策划及组织
1. 企划部收集的顾客、竞争对手信息。
2. 企划部通过各类渠道收集整理的其它商业信息。
3. 分析近期门店销售情况。
4. 会员状况分析。
5. 竞争对手促销状况分析。
6. 制定《年度企划促销计划》。年度促销计划内容主要包括：年度促销活动目的、年度促销活动主题、促销活动主要内容、促销活动时间、促销活动预算。促销年度计划经企划部经理审批后提交业务副总审批。企划部促销策划人员根据年度促销计划拟定每期《主题促销活动计划》。每期《主题促销计划》根据具体活动内容的不同，主要包括以下有关方面：目标消费群或营销环境分析、促销目的、促销时间地点、促销内容细则、分工与支持、促销时间表、促销预算、促销评估方法和内容。企划部与采购部落实需供应商支持的内容：促销商品、促销赠品、促销宣传、促销人员、促销费用。营运部负责落实促销活动在各门店的实施程序。

## 促销实施及控制程序

### 宣传准备
1. 企划部促销策划人员负责宣传文案撰写。
2. 宣传品制作：由企划部策划人员进行宣传促销品的制作。
3. 供应商赞助：由采购部根据主题促销活动计划与供应商谈判获得。
4. 宣传品移交：由企划部美工制作的宣传品直接移交门店店长，填写《宣传品发放表》；由供应商赞助的宣传品由配送中心收货后，统一配送给各门店，填写《供应商宣传品配送表》。

### 促销商品准备
1. 采购部负责根据每期主题促销计划组织相应的促销商品。采购部与供应商进行促销商品的谈判，获得在促销商品上的支持，包括买赠、折扣、特价、特殊陈列等优惠条件。采购部与供应商签署《促销商品活动协议》。采购部与供应商确定促销商品及相应的促销赞助费用。采购部向供应商下促销商品订单，并确保在促销期前3天到货及在促销期内足够的库存。
2. 配送中心负责对促销商品的优先收货及配货。采购部通知供应商提前3天送货到配送中心。配送中心根据促销商品订单对促销商品优先收货。配送中心确保最晚在促销前1天将促销商品配送到各门店。
3. 直送商品及直供商品的促销商品由供应商直接送到门店，门店优先收货。

### 赠品的准备
1. 由采购部与供应商谈判，由供应商根据主题促销活动计划提供。
2. 供应商送货时，配送中心单独填写《赠品验收单》。
3. 配送中心在各个门店配货时，把赠品一起配送给门店，填写《门店赠品配送单》。
4. 如果是由供应商直接送到门店的赠品，由门店验收并填写《门店赠品验收单》。

### 促销人员的准备
1. 由采购部与供应商谈判，由供应商根据主题促销活动计划及供应商自身的配合活动，提出促销人员派驻申请。填写《促销人员申请表》交人力资源部。
2. 人力资源部根据供应商的《促销人员申请表》招聘、面试促销人员，并进行相关的培训，经考核后录用。
3. 供应商与促销人员到人力资源部办理促销员入场手续。
4. 促销员到行政部领取促销员工牌、促销员工衣。

### 促销商品变价的准备
1. 采购部与供应商谈判，争取到促销商品优惠的价格。
2. 采购部填写《商品变价申请单》，经部门经理审核后，递交电脑部。
3. 电脑部根据确认后的《商品变价申请单》进行系统内的商品变价。
4. 电脑部根据变价清单打印促销商品特价价签。
5. 企划部美工制作促销商品特价的POP。

### 促销活动道具及设备的准备
1. 企划部提交《主题促销活动设备清单》。
2. 行政部根据《主题促销活动设备清单》，提前2天准备促销活动道具及设备。

### 促销活动落实、实施
1. 企划部制定促销活动程序，营运部负责制定同门店运作有关的业务程序。
2. 促销活动前3天，营运部将召集各门店店长参加促销活动会议，落实具体促销计划及明确职责，并将会议纪要由各门店参会人员签字确认备案。
3. 各门店店长根据促销会议内容，负责促销活动在该店的具体实施。门店负责在促销活动前一晚关门后对促销商品的重点陈列，确保有足够的位置陈列，并突出促销的感觉。门店负责在促销活动前一晚关门后对促销商品价签的更换，POP的悬挂。门店负责在促销活动前一晚关门后悬挂、张贴促销海报及宣传。门店收银员要注意促销商品的价格变更，保证正确收银及顾客解答。防损部注意维护促销现场的秩序，做好现场的安全和防盗工作。

## 厂家驻店活动管理程序
厂家驻店活动：供应商为了提高商品销售，而采取的在门店开展的系列促销活动，包括：赠品发送、促销人员驻店促销、优惠特价、特殊陈列等方式。

### 厂家驻店活动的申请
1. 供应商提前4周向采购提交《供应商促销活动申请》。
2. 采购与供应商进行促销活动的谈判。
3. 采购根据公司促销计划及供应商通道费用的缴纳情况，结合实际情况，确认供应商的促销活动。
4. 采购将确认后的《供应商促销活动申请》交采购经理、企划部经理签名确认。拟定具体厂商驻店活动计划。

### 厂家驻店信息的接收
1. 每周二企划部将本周的厂商促销计划交给营运部，其中包括促销活动的内容和方式，促销商品和价格，以及引厂进店和促销活动的人员安排计划。
2. 采购部至少提前3天将引厂驻店或促销信息交给营运部，由营运部分发到各门店。
3. 驻店活动开始前3天，采购部将促销商品订单通过电脑系统传送到各门店，门店按照促销订单接收商品。

### 进店手续的办理
1. 门店店长在接到每周促销计划后，应同厂家办理或指定促销用品接收人员办理促销用品入店手续。任何接收人员应在“促销用品管理记录表”中做相应的记录，促销用品的范围包括：促销赠品、奖券、展架、宣传品。
2. 厂家驻店活动涉及的厂家驻店人员须到人事部办理入场手续，该手续包括：填写《促销员入职申请表》；签定《促销人员管理协议书》；接受人事部培训、考核；考核通过后，到财务部缴纳相关费用(入场费、工服费、工牌费、押金等)；到人事部办理工服、胸卡手续；确定活动具体时间，促销人员到门店报到；门店店长确定活动人员排班。

### 活动的准备工作
1. 采购部在促销活动前2天将经过部门经理审批的《促销活动商品变价表》分别交电脑部及企划部美工。
2. 电脑部根据《促销活动商品变价表》在系统中进行变价并打印新价签。
3. 企划部美工根据《促销活动商品变价表》制作促销活动所用的海报和特价POP。
4. 在活动前一天，营运部将新价签、促销海报及特价POP发放到各门店。
5. 门店在活动前一天的晚上营业后，将新价签、促销海报及特价POP放置在相应的位置上，并做好促销商品的特殊陈列。
6. 每日促销活动开始前(至少15分钟)，门店主管或指定工作人员应准备好活动所需的所有用品，并将其分发到各活动厂家驻店人员的手中。统一在收银台外发放的赠品由专职发放人员准备好，并放在指定的发放台。这些用品包括：促销赠品(场内发放的赠品应贴有防损部赠品标签，以免与正常商品混淆)；促销桌和桌布(做品尝的促销、有演示的促销、有促销用具或大型展示品的应保证使用促销桌)；促销围裙(做品尝的食品促销员应使用围裙)；一次性用具(如牙签、餐巾纸等)；促销用器具及其它必须的用品。

### 活动后的收尾工作
1. 每日促销活动结束后，驻店人员须将所有活动剩余物品和用具统一交还到门店主管或其指定的人员处。该人员负责将以上用品分类归还和存放到店内指定的促销用品存放区。
2. 促销活动结束后，活动厂商须在三日内办理人员出店手续，一周之内办理物品的出店手续，该手续包括：到人事部办理退还胸卡、工服手续；到防损部办理物品退场手续，填写《物品携入携出》单，提走剩余的促销品、赠品、货架以及其它用品；到财务部办理押金退还手续；若厂商在活动结束后一周内未将用品提走，门店有权处理以上用品；促销活动结束后，门店应在活动之后协助厂商将其展示品撤出销售区。 [src: raw/ingested/促销企划手册_16.md]
