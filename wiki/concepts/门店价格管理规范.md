# 门店价格管理规范

## 一、定价

1. 定价商品的售价统一由采购部制定；采购部根据商品的进价、公司毛利指标、商品定位及市场调查结果，制定商品的售价。
2. 公司电脑系统支持一品多价，门店可根据本门店所处区域的不同，在经过市场调查后，对本店销售价格进行调整申请。
3. 采购部在核准该店所属区域市场后，决定是否同意门店销售价调整。
4. 严禁门店私自修改商品价格。

## 二、变价

变价分为总部采购变价和门店变价两种。

1. 采购根据商品进价变化、促销活动、竞争对手、竞争品种、门店销售、季节变化及市场情况，进行变价申请，由电脑部在系统中执行变价，并将变价情况及时通知门店。
2. 部分商品即将过保质期，又无法退货，采购有权做出变价申请。
3. 样品及大宗商品，采购有权做出变价申请。
4. 采购变价程序：采购主管提出申请→采购经理核批→财务确认→电脑部进行变价→通知门店。

## 三、门店变价

1. 生鲜商品变价：
   生鲜课的蔬菜、水果、鲜活水产、鸡蛋等价格波动较大的商品及门店自制熟食类，经店长批准，可进行每日随机变价；电子秤的变价，必须先由电脑部变价，再传送至电子称。

2. 价格错误、形象商品、门店促销商品的变价：
   门店发现价格错误的商品、经市场调查须变价的商品及门店开展促销活动的变价商品，填写《变价申请单》，经采购确认后，交由电脑部进行变价操作。

3. 进入删除品项商品的变价：
   经营采双方讨论，进入删除品项商品，无法退货的，经采购同意，门店可申请变价。

4. 破损、破包商品的变价：
   门店根据商品破损、破包的情况，与采购沟通退(换)货信息后，提出变价申请。

5. 门店申请变价流程：
   门店主管提出变价申请→门店店长签字确认→采购签字确认→财务部签字确认→电脑部进行变价→门店执行变价→更换价签及POP牌。

6. 变价规定及执行：
   1. 采购部应保证门店形象商品的低价。
   2. 采购可以对门店的不规范变价，向营运部经理投诉，营运部经理将于三日内将处理结果反馈采购部。
   3. 采购未能及时(不超过1天)核准门店提出的变价申请的，门店可上报营运部经理，采购部将于三日内将处理结果反馈门店。
   4. 每次电脑变价后，由电脑部立即通知相关门店及采购，门店应在第一时间进行价签和POP的更换。
