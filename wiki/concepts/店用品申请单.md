# 店用品申请单

## 概述
店用品申请单是门店用于申请自用品的标准化表单，记录请购、询价及审批信息。 [src: raw/ingested/自用品需求申请程序_39.md]

## 表单内容

### 请购询价记录
| 字段 | 说明 |
|------|------|
| 序号 | 物品序号 |
| 品名 | 物品名称 |
| 规格/型号 | 物品规格或型号 |
| 数量 | 请购数量 |
| 单价 | 物品单价 |
| 金额 | 物品金额 |
| 供应商 | 供应商1、供应商2、供应商3的报价信息 |

### 审批信息
| 字段 | 说明 |
|------|------|
| 用途 | 申请物品的用途 |
| 部门主管 | 部门主管审批签字 |
| 财务 | 财务审批签字 |
| 店长 | 店长审批签字 |
| 经办人 | 经办人签字 |
| 日期 | 申请日期 |
