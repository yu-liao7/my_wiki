# 生鲜加工间卫生要求

生鲜加工间卫生要求规定了展台、操作间、设备安全卫生及食品卫生、人员卫生等方面的标准。 [src: raw/ingested/新生鲜管理手册_32.md]

## 展台卫生要求

1. 展台每日固定进行早晚两次清洁、消毒；
2. 开店前用干净湿抹布擦去浮土即可；
3. 关店后先用消毒水浸泡过的抹布擦洗展台，再用干净湿抹布擦洗两遍；
4. 营业期间应随时用干净湿抹布擦洗展台上的污渍。 [src: raw/ingested/新生鲜管理手册_32.md]

## 操作间卫生要求

1. 及时清理所有的空箱、空盒；
2. 除非正在使用的工具、用具、工作台，都应保持清洁干净；
3. 地面不可有污水、污物；
4. 操作间应无老鼠、爬虫；
5. 垃圾应随时放入垃圾箱内并盖严；
6. 门窗、墙壁每日关店后用湿抹布清洁干净。 [src: raw/ingested/新生鲜管理手册_32.md]

## 设备安全卫生及食品卫生要求

1. 加工工具及用具使用后应立即用热水清洗干净，使其时刻保持清洁，并放置在洁净的地方；
2. 工具的消毒：在以下三种情况下应对用具、刀具、砧板、操作台进行消毒：A. 开店准备，加工食品前；B. 暂时一段时间不用（仅限于小的刀具及砧板）；C. 关店后；
3. 设备的清洗（指生肉间的锯骨机、切片机、绞肉机）：A. 按照顺序拆下零件，将所有零件浸泡在高温度洗涤灵热水中10分钟；B. 不能拆下的部分用蘸洗涤灵水的抹布擦洗，再用高压水枪使用热水冲洗干净；C. 将零件清洗干净后，用清洁抹布擦干；D. 清洗后的机身不能带有任何油腻感；E. 按照顺序将所有零件重新安装上；
4. 所有的商品应放置在清洁的储物箱内，盖好或用膜封严，放置在架子或架子车上，不允许散放在地上；
5. 在进行加工和装盒时应戴上一次性手套；
6. 随时清洗水槽，清除其中残留的微粒、细屑和化学物；
7. 保鲜库及冷冻库保持清洁，地面无污水、污渍或积水。 [src: raw/ingested/新生鲜管理手册_32.md]

## 人员卫生要求

1. 工服穿着干净整洁，无油渍、污渍；
2. 头发必须全部掖入帽子里；
3. 手部无被感染的割伤、烧伤、烫伤；
4. 无易传染的呼吸道疾病；
5. 指甲长度不可超过指尖，不可染指甲，手上不可戴饰物；
6. 不可把唾液、痰液吐在垃圾区、地板上、水槽中；
7. 已接受基本的食品卫生培训；
8. 出现以下之任何一种情况，应立即洗手：A. 上厕所后；B. 接触身体的某些部位：耳朵、鼻子、嘴巴、头发或瘙痒；C. 抽烟、吃饭、清理东西；D. 扫地、擦桌子、洗刷器皿等；
9. 正确的洗手方法：A. 使用液体洗涤剂搓洗手；B. 必要时用刷子刷洗指甲；C. 搓洗双手至少10秒钟；D. 用水冲洗约10秒钟；E. 用一次性纸巾擦手。 [src: raw/ingested/新生鲜管理手册_32.md]
