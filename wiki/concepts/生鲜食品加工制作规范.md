# 生鲜食品加工制作规范

生鲜食品加工制作规范规定了生肉操作间和熟食间的加工制作规范，以确保提供给顾客品质均一、卫生合格的生鲜食品。 [src: raw/ingested/新生鲜管理手册_32.md]

## 生肉间加工规范

| 类别 | 商品名称 | 加工规范 |
|------|---------|----------|
| 猪肉 | 硬肋排 | 将半扇排骨纵向从中间用锯骨机锯开，顺着肉切成条状 |
| 猪肉 | 猪肉馅 | 1. 将二号肉先在冷冻库中进行冷冻；2. 用锯骨机将冻硬的肉锯成3厘米见方的块状，放入绞肉机中，启动绞肉机 |
| 猪肉 | 腔骨 | 用锯骨机锯成4-6厘米的段即可 |
| 猪肉 | 猪蹄 | 将猪蹄表面的毛用刀刮干净，纵向劈开即可 |
| 猪肉 | 通脊 | 将通脊切成4-5厘米的段即可 |
| 猪肉 | 里脊 | 将里脊的一层筋膜撕去即可 |
| 猪肉 | 棒骨 | 用砍刀将棒骨从中间劈开即可 |
| 猪肉 | 五花肉 | 将肉皮上的毛刮干净，切成3厘米宽的条状即可 |
| 猪肉 | 软肋排 | 用刀将软肋排切成3-4厘米的块即可 |
| 猪肉 | 前肘 | 将表皮的毛刮干净即可 |
| 猪肉 | 大排 | 用锯骨机将整条肉横向锯成1.5厘米厚的片状即可 |
| 羊肉 | 冻肉卷 | 将冻肉卷从冷冻库中取出放入保鲜库解冻2-3小时，后将肉卷放入切片机上，加上护手板，将刀距调至1毫米，向前匀速推动肉卷，将肉切下 |
| 牛肉 | 健子肉 | 1. 切下自然块；2. 切掉表面的一些筋皮；3. 从中前部下刀，深度为肉的2/3，使其露出花筋即可 |
| 牛肉 | 牛脯 | 切成3.5厘米见方的块状 |
| 牛肉 | 牛尾 | 将牛尾整条展开，从较细的一端开始，用手指摸出关节依次切开即可 |
| 牛肉 | A里脊 | 将用保鲜膜卷好的A里脊横向切成5-6厘米厚的圆片即可 |
| 牛肉 | A外脊 | 将整条A外脊油层在下展放在砧板上，纵向切成3-4厘米厚的片即可 |
| 海鲜类 | 三绞肉 | a) 在水池中浸泡解冻；b) 用钢刷将鱼鳞擦净，将洗净的整鱼平放在砧板上；c) 用小尖刀把鱼鳃去掉再将鱼头沿根部切下；d) 横向下刀把鱼切成7-8厘米长的段，然后从背部将鱼从中间分开；e) 用刀贴着鱼骨把鱼骨剔出，再用刀刃紧贴鱼皮将鱼皮剔下；f) 将鱼肉块顺着花纹切成1.5-2厘米厚的片即可 |
| 其他 | | 将外表皮擦净即可包装 |

[src: raw/ingested/新生鲜管理手册_32.md]

## 熟食间

1. 将肠类、酱肉类食品用刀切成3厘米左右的片状；
2. 禽类食品应将整只拆分，切成5-6厘米宽的块即可；
3. 有些商品如熏火鸡腿等可直接包装。 [src: raw/ingested/新生鲜管理手册_32.md]
