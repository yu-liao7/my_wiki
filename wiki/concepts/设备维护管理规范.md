# 设备维护管理规范

设备维护管理规范明确了工程部与各门店在设备采购、建档、维护保养及维修方面的职责分工。[src: raw/ingested/营运管理手册上_41.md]

## 职责分工

1. 工程部负责各门店开业前及开业后新增设备采购管理；[src: raw/ingested/营运管理手册上_41.md]
2. 工程部负责建立各店设备台帐；[src: raw/ingested/营运管理手册上_41.md]
3. 工程部负责制定各店设备维护保养制度并检查维护保养状况，设备技术资料的整理、建档与保管；[src: raw/ingested/营运管理手册上_41.md]
4. 工程部负责设备定期维护保养及故障维修，负责设备的重大故障维修与事故原因分析与责任鉴定；[src: raw/ingested/营运管理手册上_41.md]
5. 各门店店长负责设备的日常维护保养。[src: raw/ingested/营运管理手册上_41.md]

## 设备范围

1. 机械设备：货架、生鲜加工设备、生鲜配套设备；[src: raw/ingested/营运管理手册上_41.md]
2. 冷冻空调设备：(空调)、冷冻柜、保鲜柜、风幕柜；[src: raw/ingested/营运管理手册上_41.md]
3. 电子设备：监视设备、防盗、防火报警设备、网络/电话系统；[src: raw/ingested/营运管理手册上_41.md]
4. 测量设备：电子称、台称、地称；[src: raw/ingested/营运管理手册上_41.md]
5. 收银及电脑设备：电脑、打印机、POS机等；[src: raw/ingested/营运管理手册上_41.md]
6. 其它设备。[src: raw/ingested/营运管理手册上_41.md]

## 设备档案建立

工程部负责对各门店设备建立“固定资产登记表/卡”，应明确以下内容：设备名称、设备编号、设备型号、启用时间、设备运行/使用地、设备状况。[src: raw/ingested/营运管理手册上_41.md]

## 设备运行操作管理

1. 配备经培训考核合格的运行操作人员，如电脑录入员、消防员；[src: raw/ingested/营运管理手册上_41.md]
2. 制订书面的设备运行操作规程和监控要求；[src: raw/ingested/营运管理手册上_41.md]
3. 有必要的设备以专人定岗或巡回监控方式对设备运行状况进行监控：如对冻柜、风幕柜的温度控制；[src: raw/ingested/营运管理手册上_41.md]
4. 记录运行监控结果。[src: raw/ingested/营运管理手册上_41.md]

## 设备维护保养和定期保养

1. 由工程部对各类设备制订书面的维护保养规程，明确各类设备维护保养项目，频率，方法，责任单位达到保养效果；[src: raw/ingested/营运管理手册上_41.md]
2. 编制书面的“设备维护保养计划”；各门店根据“维护保养规程”及“维护保养计划”安排合格人员进行维护保养；[src: raw/ingested/营运管理手册上_41.md]
3. 记录维护保养结果在“设备保养记录”中。[src: raw/ingested/营运管理手册上_41.md]

## 设备维修管理

1. 日常维修与小修(费用1000元人民币以下)；[src: raw/ingested/营运管理手册上_41.md]
2. 中修与大修(费用1000元人民币以上)；[src: raw/ingested/营运管理手册上_41.md]
3. 日常维修与小修各门店自行实施，故障原因与维修结果记录在“设备维修登记表”上；由店长签字；[src: raw/ingested/营运管理手册上_41.md]
4. 各门店在设备或设施使用过程中发现重大故障(1000元人民币以上)需向工程部提出维修申请，维修申请要求由店长填写“维修申请单”后报工程部；“维修申请单”中应写明以下内容：提出维修部门、故障内容、故障地点、故障发现时间；[src: raw/ingested/营运管理手册上_41.md]
5. 对需紧急维修的项目，各门店可以和工程部电话联系，提出口头维修申请，工程部应将维修申请记录在“维修申请单”中。[src: raw/ingested/营运管理手册上_41.md]
