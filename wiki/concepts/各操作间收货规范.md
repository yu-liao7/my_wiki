# 各操作间收货规范

各操作间收货规范规定了生肉操作间、熟食操作间、果蔬间的收货标准和验收方法。 [src: raw/ingested/新生鲜管理手册_32.md]

## 生肉操作间

收货标准参见采购部“生鲜品质标准”，去水标准如下：

| 商品类别 | 商品名称 | 去水标准 |
|---------|---------|----------|
| 猪肉 | 二号肉 | 3% |
| 猪肉 | 白条肉 | 3% |
| 猪肉 | 通脊 | 10% |
| 猪肉 | 里脊 | 10% |
| 猪肉 | 猪腰 | 10% |
| 猪肉 | 猪肝 | 10% |
| 禽类 | 鸡肉 | 乌鸡（10%） |
| 禽类 | 兔子 | 10% |
| 水产类 | 鱼类 | 3% |
| 水产类 | 虾类 | 5-8% |
| 水产类 | 水发干货 | 5%（海蛰皮15%） |

[src: raw/ingested/新生鲜管理手册_32.md]

## 熟食操作间

| 商品类别 | 验收方法 | 验收标准 | 备注 |
|---------|---------|----------|------|
| 熟肉制品 | 目测、嗅、触摸 | 包装箱干净，食品干净，颜色鲜亮，外皮不皱；具有熟肉制品固有的香味；不粘手 | |
| 豆制品 | 目测、嗅 | 包装箱干净，食品干净，颜色鲜亮；具有豆制品固有的香味，无酸味 | |
| 泡菜制品 | 目测、嗅 | 包装箱干净，食品干净，颜色鲜亮，菜质新鲜，无霉点；具有泡菜特有的香味 | 收货时应将泡水重去 |

[src: raw/ingested/新生鲜管理手册_32.md]
