# 发票领用程序

## 备注

1. 开具发票必需按金额选择相应面值发票填写。[src: raw/ingested/发票领用程序_19.md]
2. 所有领用发票（已使用、未使用）由收银领班交接管理。[src: raw/ingested/发票领用程序_19.md]
3. 顾客一个月内持电脑小票至相对应店服务中心开具发票。[src: raw/ingested/发票领用程序_19.md]

## 发票领用登记表

登记表包含以下字段：[src: raw/ingested/发票领用程序_19.md]

| 领进 | 领出 | 收回 |
| --- | --- | --- |
| 日期 | 日期 | 收银中心 |
| 发票号 | 发票号 | 日期 |
| 领进人 | 领出人 | 发票号 |
| | | 交回人 |
| | | 收回人 |

表格底部设有合计栏。[src: raw/ingested/发票领用程序_19.md]
