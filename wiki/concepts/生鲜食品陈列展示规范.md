# 生鲜食品陈列展示规范

生鲜食品陈列展示规范规定了生鲜食品的展示要求，以展示给顾客一个整洁的购物环境，调动顾客的购买欲。 [src: raw/ingested/新生鲜管理手册_1.md]

## 商品的摆放要求

1. 商品的摆放整齐笔直、外观干净；
2. 发现包装破损、包装膜松懈的商品应立即返工，重新包装（切记注意包装日期）；
3. 同类商品摆放在一起，牛、羊肉制品应与猪肉制品分开摆放；
4. 员工有责任保持展柜商品量的充足，出现空档应立即补充；
5. 冷冻、冷藏柜的商品应保证价签位置的准确性。 [src: raw/ingested/新生鲜管理手册_1.md]

## 价签、POP的要求

1. 所有的标价必须正确，保证每个商品都有标价；
2. 每个POP必须用POP袋套住，特惠POP必须标出原价；
3. 所有价格牌、POP必须干净、整齐一致；
4. 在蔬菜陈列处，如有特惠商品，可用特惠POP标出，POP在原价钱牌下面。 [src: raw/ingested/新生鲜管理手册_1.md]

## 展柜的要求

1. 展柜的照明应保持良好，灯具无损坏；
2. 员工有责任随时保证展柜的清洁；
3. 主管对展柜的温度应定时进行追踪记录（见工作检查清单），出现异常应立即通知设备组（化霜时间除外）。 [src: raw/ingested/新生鲜管理手册_1.md]

## 果蔬的陈列要求

1. 果蔬陈列要讲究颜色的搭配，如红、黄、绿相间等；
2. 促销时可运用堆头方式进行，通过量贩陈列吸引顾客；
3. 堆头可通过垫高的方法达到丰满；
4. 把毛利高、销售好的商品摆在堆头；
5. 及时补货，覆盖陈列架，保持货架丰满；
6. 做好先进先出；
7. 变质的商品不能上架；
8. 所有的菌类、菇类商品应放冷藏柜。 [src: raw/ingested/新生鲜管理手册_1.md]

## 熟食的陈列要求

### 套餐柜

1. 周一到周五，所有产品都用浅盘，这样看起来好看并可减少损耗；
2. 周六、周日、节假日，小炒除了包类都可用深盘，其中要根据当天的营业额来灵活调整；
3. 早班开店时水温要开到60摄氏度，没客人时把玻璃门关上；
4. 有质量问题的商品不能出售；
5. 价格牌要与电子称相符。 [src: raw/ingested/新生鲜管理手册_1.md]

### 熟展柜

1. 卤水产品只开灯即可，不能开温度；
2. 其他商品开温度到60摄氏度；
3. 所有商品价格牌与电子称一致；
4. 所有商品在开门和交接班时要保持丰满，但切片的商品为了减少损耗，可在周一到周五减少一些，在下面垫上成块的商品可达到同样丰满的效果；
5. 卤水要每15分钟翻动一次，并洒上香菜调色；
6. 有质量问题的商品不能出售和陈列。 [src: raw/ingested/新生鲜管理手册_1.md]

## 肉类的陈列要求

1. 开门前玻璃要干净；
2. 肉类商品可做关联陈列，陈列柜上可放相应的调味品；
3. 包装内有血水时要及时收回，重新打包；
4. 变质商品坚决不能上货架；
5. 肉类商品应每小时整理一次货架；
6. 肉类陈列区域要保证地面无积水。 [src: raw/ingested/新生鲜管理手册_1.md]

## 水产的陈列要求

陈列原则：要求视觉饱满，颜色搭配和谐，装饰有新意，有正确的货架标签、POP，商品摆放有利顾客拿取，不易掉落，损耗少。 [src: raw/ingested/新生鲜管理手册_1.md]

### 冰台

1. 冰台的冰不能太多太高，冰面要有倾斜度，让远处的顾客一眼看到冰鲜鱼；
2. 冰鲜鱼的颜色要搭配和谐，装饰有新意，每天有不同的花样；
3. 冰鲜鱼要充分和冰接触，防止鱼因脱水而变质；
4. 陈列在冰台的包装商品，要高出冰面2/3，不能埋入冰内，而且要归类陈列，如急冻海产品、包装活鲜类；
5. 三文鱼柳、鱼头、北极贝等即食产品要和冰鲜鱼间隔开，防止细菌感染；
6. 每种冰鲜鱼要有醒目的价格牌且一一对应；
7. 保持有干净的柠檬水，方便顾客洗手；
8. 冰鲜鱼陈列将要风干时，必须用盐冰水泡5分钟后再陈列，保证色泽光亮新鲜。 [src: raw/ingested/新生鲜管理手册_1.md]

### 展示鱼池

1. 淡水鱼和海水鱼要分开陈列；
2. 鱼池内的鱼不能太少，保证每个品种在晚上8点前不少于陈列标准要求；
3. 不能有反肚的鱼、死虾、死蟹在池内；
4. 价格牌正确无误，每一个鱼池至少有一个价格牌；
5. 保持鱼池、海鲜陈列台干净，鱼池玻璃清洁明亮。 [src: raw/ingested/新生鲜管理手册_1.md]

### 急冻展示柜

1. 陈列整齐有序，且饱满以方便顾客拿取；
2. 不能有包装破损、漏气的商品，或者商品结霜、结冰现象；
3. 有与商品相对应正确的价签。 [src: raw/ingested/新生鲜管理手册_1.md]
