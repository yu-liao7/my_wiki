# 营业员日常工作规范

营业员是卖场日常运营的核心执行者，其工作贯穿开店前、营业中、离店前以及每周、每月的周期性任务。本规范汇总营业员的工作职责、常用工具及各项工作内容。 [src: raw/ingested/营业员的日常工作DOCX 文档_40.md]

## 工作职责

1. 保持整洁的仪容，以及整齐干净的制服。
2. 负责商品的品质、卫生及新鲜度。
3. 保持部门工作环境的整洁。
4. 负责台面的陈列、标价及商品包装。
5. 以亲切热忱的态度面对顾客，专业、热忱地回答顾客的问题并提供最好的建议。 [src: raw/ingested/营业员的日常工作DOCX 文档_40.md]

## 基本工具和使用重点

**随身必备工具**：笔、刀片、纸。

**常使用工具**：拖板车及栈板/地台。 [src: raw/ingested/营业员的日常工作DOCX 文档_40.md]

**使用重点**：
1. 工具及设备小心使用，不可以嬉戏。
2. 商品陈列堆积要注意其安全稳固。
3. 遵守货品先进先出之原则。
4. 及时小心处理排面上任何不良商品（破裂物、过期品等）。
5. 不可以妨碍顾客购物。 [src: raw/ingested/营业员的日常工作DOCX 文档_40.md]

## 开店前工作

### 补货
1. 在卖场登记缺货商品。
2. 到仓库拿取缺货商品。
3. 补满货架及促销台。

注意：商品的陈列堆积要注意其安全稳固，遵守商品的先进先出原则。 [src: raw/ingested/营业员的日常工作DOCX 文档_40.md]

### 整理排面
1. 补商品，拉排面，使货架整齐丰满。
2. 注意陈列方式、价格标签的正确及包装的完整。 [src: raw/ingested/营业员的日常工作DOCX 文档_40.md]

### 整理仪容
保持整洁的仪容，以及整齐干净的制服。 [src: raw/ingested/营业员的日常工作DOCX 文档_40.md]

### 清洁
1. 整理清洁排面及商品。
2. 整理清洁货架。
3. 清空走道上的杂物，及时通知及协助清洁人员随时清洁卖场。 [src: raw/ingested/营业员的日常工作DOCX 文档_40.md]

### 检查
1. 检查及确认卖场货架及促销台商品，看是否补满。要求整洁，丰满。
2. 检查及确认货架、走道及仓库的整洁。要求货架整洁，通道通畅及地面整洁，仓库地面整洁，货品归类摆放。
3. 检查短期保质期商品（干货杂货、生鲜及冷冻/冷藏食品）的鲜度、品质及到期日。
4. 检查确认商品的价格牌、条码、POP，看是否正确。 [src: raw/ingested/营业员的日常工作DOCX 文档_40.md]

## 营业中工作

### 整理仓库
1. 在部门主管的带领下整理仓库。
2. 按照先进先出原则进行整理。 [src: raw/ingested/营业员的日常工作DOCX 文档_40.md]

### 巡视卖场
1. 随时注意器材或用具的损坏及异常发生，立即通知主管或负责人处理。
2. 保持工作环境的整洁干净。 [src: raw/ingested/营业员的日常工作DOCX 文档_40.md]

### 处理商品
1. 对排面上任何不良商品（破裂、标识不清、缺件、瘪罐、变形过期），立即下架并做退货或相关处理。
2. 遵守商品先进先出原则。
3. 整理及处理已到货的商品。
4. 时时维持卖场货架满陈列。
5. 中午检查是否有到货商品未处理。 [src: raw/ingested/营业员的日常工作DOCX 文档_40.md]

### 服务顾客
1. 留意顾客的意见，并转告主管。
2. 以亲切热忱的态度服务顾客，随时帮助顾客解决问题。 [src: raw/ingested/营业员的日常工作DOCX 文档_40.md]

## 离店前工作

1. **汇报**：向主管汇报当日特殊事件。
2. **清洁工作**：完成与晚班人员之工作交接。
3. **清仓整理**：确定完成仓库整理及清洁工作。
4. **满陈列**：确认卖场满陈列（货架及促销台）。
5. **到货处理**：确定已到货商品处理完毕。 [src: raw/ingested/营业员的日常工作DOCX 文档_40.md]

## 每周工作

1. **清除退货**：确实依退货程序清除退货商品。
2. **清洁工作**：依清洁计划确实执行清洁工作（卖场、仓库、货架、寄仓区）。
3. **处理滞销品**：定期检查电脑库存，及时处理滞销品。
4. **汇总市调**：将市调后的结果填写于市调表，立即交给主管。
5. **换促销台**：依促销台计划表安排更换促销台（DM商品一律放在促销台及促销区）。 [src: raw/ingested/营业员的日常工作DOCX 文档_40.md]

## 每月工作

1. **仓库整理**：确实依据一种商品一个位置的原则堆放仓库之库存商品。
2. **检查库存差异**：检查电脑库存量与实际库存是否有差异，并将结果告知主管。
3. **每月盘点**：做好盘点准备工作。 [src: raw/ingested/营业员的日常工作DOCX 文档_40.md]
