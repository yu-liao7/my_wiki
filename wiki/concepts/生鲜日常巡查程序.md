# 生鲜日常巡查程序

生鲜日常巡查程序规定了生鲜部日常巡查的频次、内容和处理方式，以确保生鲜区的各项工作符合规范。 [src: raw/ingested/新生鲜管理手册_1.md]

## 职责

- 生鲜主管负责整个生鲜区日常巡查工作及人员管理；
- 生鲜经理负责对日常巡查中的生鲜管理检查和生鲜商品的品质控制。 [src: raw/ingested/新生鲜管理手册_1.md]

## 检查频次和内容

1. 生鲜商品日常巡查的频次规定为每日四次，具体的巡查时间安排为：开店检查；营业期间不定时的检查（两次/天）；关店检查。
2. 每日所进行的检查应包括以下几项工作：商品质量及展示情况；环境卫生；设备设施状况；人员卫生及服务质量。
3. 生鲜加工中心主管将针对不同的检查范围及检查时间制定详细的“生鲜部日常巡查清单”，明确不同检查范围及检查时间所应巡查和确认的内容。
4. 生鲜主管制定检查清单应按质量体系文件控制的要求进行控制。 [src: raw/ingested/新生鲜管理手册_1.md]

## 生鲜部日常巡查

1. 生鲜主管及生鲜经理依据生鲜商品工作检查清单以及各操作工作规范进行开店前、营业期间及关店后的检查，每日的开店前检查应在正式开店前完成；每天的营业期间检查应为两次；每日关店后的检查应在关店后进行。
2. 生鲜部主管的检查结果将有如下三种情况：
   - 合格（所检查的每项活动符合相应操作规范）；
   - 不合格，可当场纠正（检查中发现不符合规范的操作，但现场可立即纠正）；
   - 不合格，需采取纠正和预防措施（检查过程中发现不合格的情况，重复发生或当场无法纠正），应按照程序登记上报。
3. 主管检查后应将存在的问题填写在检查单的相应栏（关店时发现的问题请记录在相应操作间的“备注”栏）并在“检查人签字”一栏签字。
4. 生鲜主管检查后将检查单钉在店长办公室的提示板上；店长跟踪解决。 [src: raw/ingested/新生鲜管理手册_1.md]
