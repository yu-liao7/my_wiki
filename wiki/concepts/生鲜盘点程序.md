# 生鲜盘点程序

生鲜盘点程序明确了盘点的程序和要求，以保证盘点数据的准确，从而提供正确的毛利报告。 [src: raw/ingested/新生鲜管理手册_1.md]

## 职责分工

1. 生鲜经理负责制定各部门目标毛利值；
2. 生鲜主管负责制定本部门盘点单、核查盘点数据，并将其与系统的差异数量作出报表交营运部财务部；
3. 电脑部录入员负责将相关数据录入系统，提交并打印出毛利报告；
4. 生鲜部采购、生鲜主管及生鲜经理负责查找实际毛利与目标毛利的差异原因；
5. 生鲜主管及生鲜经理负责制作“生鲜部损益表”；
6. 盘点员负责盘点数据的准确。 [src: raw/ingested/新生鲜管理手册_1.md]

## 盘点时间

1. 生鲜商品的盘点定为每月一次（每月月底）；
2. 特殊规定生肉、熟食操作间盘点时间为下午17:00将开始，仅盘库里的商品。 [src: raw/ingested/新生鲜管理手册_1.md]

## 盘点程序

1. 各操作间人员负责在盘点前一日制作出本操作间的盘点单（注意不要有遗漏）；
2. 各操作间于盘点日按照作业指导书-盘点方法ABC三种方法认真盘点，填写盘点单，盘点员签字，当日负责盘点的主管核查后在“核查员”处签字；
3. 电脑部录入员负责盘点单的录入（注意应在确认盘点日所收货品已全部录入系统后进行），打印盘点差异表；
4. 主管负责完成盘点差异表的复核盘点。差异数量调整必需财务部与防损部签字复核；
5. 电脑部录入员负责按照审核后的“调整数量”重新录入系统，并打印毛利报告交生鲜经理、店长及财务部；
6. 如报告显示毛利异常，生鲜主管、生鲜经理及店长应立即查找原因，对于毛利异常的情况应作出相应解释，报告交领导审批后复印存档财务部。 [src: raw/ingested/新生鲜管理手册_1.md]

## 各操作间盘点方法

盘点方法的种类：
- 方法A——适用于生肉司、熟食间的盘点
- 方法B——适用于包装材料的盘点
- 方法C——适用于果蔬司的盘点 [src: raw/ingested/新生鲜管理手册_1.md]

### 方法A

1. 下午17:00开始盘点冷藏库及冷冻库内的单品；
2. 逐一称重单品，将重量填写在相应“盘点数量”栏；
3. 对无库存的单品应在其数量栏填写“0”，而不能空着不填；
4. 盘点员盘点完成后在“盘点员”一栏签字，将盘点单交主管核查；
5. 盘点结束，清洁盘点区域，将所有库存单品摆放整齐，以备次日开店。 [src: raw/ingested/新生鲜管理手册_1.md]

### 方法B

1. 于盘点日按照盘点单上所列单品的顺序进行清点；
2. 按照盘点单上所注单位进行认真清点（一定注意盘点单上每一单品所对应的清点单位是“箱”、“个”等）；
3. 对无库存的单品应在其数量栏填写“0”，而不能空着不填；
4. 盘点员盘点完成后在“盘点员”一栏签字，将盘点单交主管核查；
5. 盘点结束，清洁盘点区域，将所有库存单品摆放整齐。 [src: raw/ingested/新生鲜管理手册_1.md]

### 方法C

1. 晚上19:00将台面补满后开始盘点库里的单品；
2. 逐一称重单品，将重量填写在相应“盘点数量”栏；
3. 对无库存的单品应在其数量栏填写“0”，而不能空着不填；
4. 盘点员盘点完成后在“盘点员”一栏签字，将盘点单交主管核查；
5. 当日关店后或次日开店前盘点台面上的剩余商品，以“+”的方式补记入盘点单相应数量栏（如一单品库内存货为2.646KG、台面上剩余存货重量为1.254KG，则记录为“2.646+1.254”即可）；
6. 盘点员完成后交主管核查；
7. 盘点结束，清洁盘点区域。 [src: raw/ingested/新生鲜管理手册_1.md]
