# 第一章：生鲜管理部门和职责

### （一）生鲜采购
1. 负责与生鲜供应商的谈判与对供应商的管理；
2. 负责生鲜商品的日常采购；控管生鲜商品进货品质，确保运输途中的商品保鲜，
控管路途损耗；
3. 负责生鲜部门新商品的引进和滞销商品的汰换；
4. 负责生鲜部原材料及耗材的采购；

### （二）生鲜经理
1. 负责生鲜部门的人员管理及工作安排；
2. 完成门店生鲜部门销售指标、毛利指标、损耗控制指标；
3. 负责门店生鲜商品陈列标准、卫生标准及品质标准的达标；
4. 负责按照生鲜商品规范操作程序培训员工；
5. 负责生鲜部日常采购计划；负责换季生鲜商品组织结构的落实和调整；
6. 负责生鲜部商品促销计划和实施；关注单品销售，积压商品及时处理；
7. 负责安排市场调查，保证生鲜部门商品的市场竞争力；

### （三）生鲜主管
1. 协助生鲜经理进行人员管理及工作安排；
2. 负责门店生鲜商品陈列的调整、卫生检查及品质控制；
2. 负责门店生鲜商品的收货和盘点；
3. 负责门店生鲜商品的损耗控制；
4. 负责生鲜加工过程的商品卫生、品质控制；严格控制加工过程中的商品损耗；

### （四）生鲜理货员
1. 负责门店生鲜商品的陈列、整理、卫生维护及品质控制；
2. 负责门店生鲜商品的盘点；
3. 负责门店生鲜商品的弃货申请和损耗控制；
4. 负责顾客对生鲜商品需求的反馈；
5. 负责生鲜商品的加工，包括果蔬的加工、熟食及半成品的制作等
6. 严格按照生鲜标准及规范操作程序加工生鲜商品，确保商品的卫生和质量；
按需制作，保证商品的足量供应和新鲜度；
7. 严格控制生鲜商品加工过程的商品损耗。

# 第一节3面包房产品品质标准
3·1蛋糕类：表面金黄油润，深浅一致无焦斑，膨松饱满，刨面气孔均匀，群体有弹性，松软面微韧，无粗糙感，不粘牙，无蛋腥味。 3·2酥类：油润鲜艳，腰边象牙色，馅心端正，厚薄均匀，酥层清晰，入口香酥。 3·3饼干类：色泽金黄，入口香脆，有牛油划果仁香味，无松散现象。 3·4面包类：呈金黄色，表面有光泽，内部蜂状，松软有弹性，口感香甜松软。

# 第一节4水产品质标准
4·1鱼  类：眼球饱满，角膜透明且清亮。鱼鳃色泽鲜红，鳃丝清晰，粘液透明无异 味，鱼肉坚实有弹性，以手指压后凹陷立即消失，无异味。鱼体表有透明粘液，鳞片 鲜明有光泽，贴附鱼体牢固，不易脱落。腹部不膨胀，内脏清晰可辩，无异味。 4·2软体类：色泽鲜艳，表皮呈原有色泽，有亮泽，粘液多，体型完整，肌肉柔软而光滑。 4·3贝壳类：受刺激时贝壳紧闭，两贝壳相碰时发出实响。 4·4蟹  类：蟹壳纹理清楚，用手指夹持背腹，两面平置，脚爪伸直不下垂，肉质坚实，气味正常。 4·5虾  类：外壳有光泽，半透明，肉质紧密，有弹性，甲壳紧密裹着虾体，气味正常无异味。

# 第一节5猪肉品质标准
5·1白条肉 色泽：鲜红、膘亮白，指压有弹性。 大小：45公斤左右。 规格：带皮、肘子、骨、蹄。 肥瘦标准：膘厚不超过1·5一2·OCM。 备注：无血脖、板油、腺体隔膜等杂物，有检疫章。 5·2五花肉 色泽：鲜红、膘亮白，指压有弹性。 规格：带皮、无骨。 肥瘦标准：膘厚不超过1·5-2·OCM。 备注：无腺体等杂物。 5·3排骨 色泽：鲜亮、骨色白。 规格：无皮、有骨、少或者无肥肉。 肥瘦标准：少或者无肥肉。 备注：无隔膜、腺体等。 5·4猪蹄 色泽：表皮千净，色泽干净。 规格：带皮、有骨。 标准：少或者无肥肉。 备注：无毛，无烫痕。 5·5 猪腰 色泽：暗红色，指压有弹性。 标准：无表层筋膜等杂物。 5·6猪肝 色泽：暗红色，指压有弹性。 大小：不高于1·5公斤/块。 标准：无隔膜、隔柱肌、苫胆等杂物。 5·7猪心 色泽：暗红色，指压有弹性。 大小：0·25公斤左右。 标准：无淤血、血管等杂物。

# 第一节6牛羊肉品质标准
1. 羊肉卷清真
去净大小骨及软骨、腰油、板筋、护档油、尾汕，无淤血，不变质，肉质新鲜，部位齐全，符合食品卫生标准。
2. 肉清真分割牛
分割部位成自然状，刀切面平整，色泽鲜亮，肥瘦相间，外表清洁，无血渍，肉质鲜嫩，无酸味、异味。

# 第一节7禽类品质标准
感官标准：眼球饱满，皮肤有光泽，肌肉切面发光，外表微干或微湿润，不粘手，指压后的凹陷立即恢复。 产品原料：生长期在60天以内的肉鸡，有检验检疫证书。 产品加工：应符合食品卫生的有关规定。 产品包装：用吹塑薄膜包装，吹塑薄膜应符合GB4456标准。 产品运输：公路运输应使用符合卫生要求的冷藏车或保温车，市内运输也可使用密封防尘车辆。

# 第二节、生鲜加工间、销售区域等各方面的卫生要求及标准

# 第二节1展台卫生要求
1. 展台每日固定进行早晚两次清洁、消毒；
2. 开店前用干净湿抹布擦去浮土即可；
3. 关店后先用消毒水浸泡过的抹布擦洗展台，再用干净湿抹布擦洗两遍；
4. 营业期间应随时用干净湿抹布擦洗展台上的污渍；

# 第二节2操作间卫生要求
1及时清理所有的空箱、空盒； 2除非正在使用的工具、用具、工作台，都应保持清洁干净； 3地面不可有污水、污物； 4操作间应无老鼠、爬虫； 5垃圾应随时放入垃圾箱内并盖严； 6门窗、墙壁每日关店后用湿抹布清洁干净；

# 第二节3设备安全卫生及食品卫生要求
1. 加工工具及用具使用后应立即用热水清洗千净，使其时刻保持清洁，并放置在洁净的地方
2. 工具的消毒；在以下三种情况下应对用具、刀具、砧板、操作台进行消毒
A·开店准备，加工食品前 B·暂时一段时间不用(仅限于小的刀具及砧板) C·关店后
3. 设备的清洗（指生肉间的锯骨机、切片机、绞肉机）
A·按照顺序拆下零件，将所有零件浸泡在高温度洗涤灵热水中10分钟 B·不能拆下的部分用蘸洗涤灵水的抹布擦洗，再用高压水枪使用热水冲洗干净； C·将零件清洗干挣后，用清洁抹布擦干； D·清洗后的机身不能带有任何油腻感； E·按照顺序将所有零件重新安装上；
4. 所有的商品应放置在清洁的储物箱内，盖好或用膜封严，放置在架子或架子车上，不允许散放在地上。
5. 在进行加工和装盒时应戴上一次性手套；
6. 随时清洗水槽，清除其中残留的微粒、细屑和化学物。
7. 保鲜库及冷冻库保持清洁，地面无污水、污溃或积水。

# 第二节4人员卫生要求
1. 工服穿着干净整洁，无油渍、污渍。
2. 头发必须全部掖入帽子里。
3. 手部无被感染的割伤、烧伤、烫伤。
4. 无易传染的呼吸道疾病。
5. 指甲长度不可超过指尖，不可染指甲，手上不可戴饰物。
6. 不可把唾液、痰液吐在垃圾区、地板上、水槽中。
7. 己接受基本的食品卫生培训。
8. 出现以下之任何一种情况，应立即洗手：
A·上厕所后 B·接触身体的某些部位：耳朵、鼻子、嘴巴、头发或瘤痒 C·抽烟、吃饭、清理东西 D·扫地、擦桌子、洗刷器皿等
9. 正确的洗手方法
A·使用液体洗涤剂搓洗手； B·必要时用刷子刷洗指甲； C·搓洗双手至少10秒钟； D·用水冲洗约10秒钟； E·用一次性纸巾擦手；

# 第三章：生鲜操作程序（生鲜按原材料的分类：生肉制品、熟食制品、果蔬）

# 第一节、生鲜商品收货和存放管理
1. 生鲜商品订货
1）加工间工作人员对本操作间需订购的原材料填写订货申请，签字后交生鲜主管。 2）生鲜加工主管签字，汇总到生鲜经理审核签字后，转由采购员负责采购。 3）门店生鲜商品的订货方法： A每日下午4:00后由生鲜主管根据生鲜商品的存货量及销售量估算本门店明日的订货量。 B将各商品的订货数量记录在《商品订货申请表》一式两联；(无须订货的商品应在备注栏划斜线，不允许空白)，一联交生鲜经理审核签字后转交信息部打印订单，后转交生鲜采购员。 C由生鲜采购员电话通知本地供应商订货数量后；订单存放在收货部参照验收货。 D现金自采订单采购员根据门店订货申请制定现金采购计划。
2. 商品收货
1）收货抽样要求按“生鲜商品验收规范”执行； 2）生肉类收货时应向厂家索取“卫生检疫合格证”；
3. 收货记录
3·1收货部按照门店前一日的订货数量进行收货，将实际收货重量(去水后)记录在订单的实际“收货”栏。 3·2生鲜员工将所收商品存放至相应区域，在订单上签字，订单保留在收货信息部。 3·3验收不合格商品的处理 A、对验收不合格商品的处埋权限规定如下：对送货与订单上数量的不符，差异低于30%，可由主管直接处理；差异高于30时主管应报生鲜经理，生鲜经理有责任追踪事件结果。对于质量的不符，应由主管决定是否拒收。若拒收的商品数量较大或品种较多以至于影响开店，主管应请示店长或生鲜采购作出决定。 B、对不合格商品的处理有了相应的处理决定后，操作如下： 收货部在该商品订单的收货数量处，记实际收货数量(若拒收，则填“0”)，备注原因，收货主管在订单上签字后交录入员。 C、对于收货过程中发生的严重事件，如：因严重质量问题拒收、严重或多次延迟送货、送货数量严重或多次不符等，生鲜经理应及时跟生鲜采购沟通更换供应商。
4. 商品存放要求
A、生鲜主管按照《生鲜商品储存条件和控制要求》带领员工妥善存放收进的生鲜商品，该规范应明确以下内容： 1）储存商品收货日期的标识方法； 2）各类生鲜商品的储存温度、储存方式； 3）如何确保“先入先出”的准确实施； B、主管负责带领员工按照《生鲜商品展示规范》进行操作，以确保商品在以最佳的状 态展示给顾客；存放过程中不合格商品的处理 4）主管及员工对巡查过程中发现的不合格商品应立即从展台或储存箱上撤出，并做如下处理: A·重新包装 (对不符合包装规范要求的商品) B·对变质的商品应立即隔离存放，并作出标识 C·对于弃货商品应填写《弃货单》 5）日常检查 A、每日配送中心生鲜加工间、各门店生鲜销售区域将有四次检查:开店、营业期间(两次)、关店检查。 B、主管根据 《生鲜部工作检查清单》对各操作间、生鲜销售区域进行检查、记录。 C、不合格项的处理参见《生鲜部日常巡检程序》。 6）定期盘点：生鲜商品每月将进行盘点(月末)。

# 第三节、果蔬间工作规范：规范果蔬操作间的各种操作，便员工掌握正确的方法，以提供给顾客品质均一的高质量果蔬产品。
1. 商品收货参见作业指导书-各操作间验收货规范
2. 商品储存要求
1）收货时将商品的有效期标注在周转箱外，所有商品遵循"先入先出"的规则进行销售； 2）存放在冷藏库内的商品应整齐码放在层架上，标注有效期； 3）暂存在冷藏库内需弃货的商品应隔离摆放并作出标识；
3. 商品展示要求
1）台面要求丰满，不能露出展台底面； 2）摆放规则，同名称的商品摆放在一起； 3）价签名称准确、清晰，与价签下方所放置的商品一致； 4）不能有过期商品滞留在台面上； 5）不能有包装破损的商品滞留在台面上； 6）状态不佳的商品(如:起皱、发软、变色、腐烂)不能出现在台面上。
4. 员工卫生要求
1）工作期间必须穿着工服，工服的所有扣子必须扣上，工帽佩带整齐 2）工服保持干净，不能带有污渍 3）指甲长度不能超过指尖，且指甲内不可有污物
5. 洗手的要求
1）出现以下任何一种情况，须洗手后才能开始工作 A·上厕所后 B·用餐后 C·抽烟后 D·触摸身体的某些部位 (如：耳、鼻、头发或瘩痒等) E·接触过其他非卫生的物品后
6. 正确的洗手方法
A·洗手时应使用香皂或洗涤剂 B·必要时用刷子刷洗指甲 C·用水冲洗10秒左右 D·用干净的毛巾将手擦干净
7. 操作间卫生要求
1）地面应保持清洁千净(除加工过程中)，不能有污渍或大片水渍； 2）加工净菜后应立即将地面清扫干净； 3关店时应将地面拖洗干净； 4）垃圾桶应随时保持盖好的状态； 5）操作台除非正在操作，操作台应是光洁的，且各种用具放置归位； 6）刀具应随时清洗干净，放置归位； 7）周转箱应保持清洁，码放整齐。

# 第四节、面包房工作规范：
规范面包房的各种操作，使得其运作标准符和规范运作的要求，以提供给顾客品质均一的高质量面包。

## 一、商品展示要求
1）台面要求丰满，不能露出展台底面。 2）摆放规则，同名称的商品摆放在一起。 3）价签名称准确，与所包装商品一致 4）价签应贴在包装的右下角 5）不能有过期商品滞留在台面上 6）不能有包装破损的商品滞留在台面上 7）不合格的商品(如:烘烤过度或不足、形状不合格、重量不合格等等)不能出现在台面上。二、操作间内原料存放要求 1）成品应与未烤制的坯子分开摆放，对于存放在冷藏库的饼坯应标出存放日期、有效日期 2）原材料与成品分开摆放； 3）原材料不能直接放置在地面上(如:奶粉、面粉等应放置在层架上)； 4）同类原材料应整齐摆放在一起，固定位置，不能随处摆放； 5）保鲜柜温度应保持在0-4摄氏度，冷冻柜温度应保持在-10至-15摄氏度； 6）弃货应隔离放置并贴上标识；

## 三、员工卫生要求
1）进入操作间必须穿着工服，佩戴围裙 2）工服的所有扣子必须扣上，围裙系好，头发全部掖入帽内 3）工服必须保持干净，不能带有黑色油渍 4）指甲长度不能超过指尖，且指甲内不可有污物 5）男员工不许留长发，女员工不许化妆，手及腕部不许佩带首饰 6）离开操作间前须脱下围裙 7洗手的要求 1）拿食物的手弄脏后应立即清洗干净，接触任何可能的不洁物后必须洗手，这包括： A·上厕所后 B·触摸身体的某些部位：耳朵、鼻子、嘴巴、头发或搔痒 C·抽烟 D·吃饭 E·清理东西 F·扫地 G·洗刷器皿 2）正确的洗手方法 A·使用液体洗涤剂搓洗手和双臂直至肘部 B·必要时用刷子刷洗指甲 C·搓洗双手至少10秒钟 D·在流水下洗手，让水彻底冲洗肘部直到指尖 E·用一次性纸巾擦手

## 四、操作间卫生要求
1. 地面：开店前、关店后应将地面用拖布拖洗干净；地面应随时用拖布拖洗，保持清洁干净，不能有污渍或大片水溃
2. 操作台：
A、开店前、关店后应用热水将操作台清洗干净； B、操作台上不能放置原材料外包装袋或其它不卫生的物品；
3. 原材料容器
1）将原材料容器放入水池内； 2) 注入热水，浸泡五分钟； 3) 用百洁布或百洁球蘸洗涤灵，用力擦洗容器的里、外面用调试好的温水进行冲洗； 4) 容器无腻、涩的感觉并直至里外面光滑；
4. 墙面、窗台
1）用抹布蘸洗涤灵水擦洗墙面、窗台； 2）用抹布蘸清水擦洗墙面、窗台至表面光亮；
5. 水池、抹布
1）用消毒水浸泡洗净的抹布5分钟，在用清水清洗干净，打开晾干； 2）用消毒水冲洗水池并冲洗下水道；
6. 设备
1）烤炉 A·关闭电源，打开炉门降温； B·将接油的盛水托盘取出、倒掉水； C·将清洗剂喷洒在烤炉内壁、靠架和表面，浸三分钟； D·用百洁布蘸温水，用力擦洗，直至内壁和烤架光滑； 2）压面机 A·用蘸温水的抹布擦洗压面机表面； B·擦洗压面机的盛面槽； C·擦洗压面机的底座； D·将压面机折叠竖起；； 3）和面机 A·用蘸温水的抹布擦洗和面机的表面 B·擦洗盛面缸的钢架； C·擦洗和面机的底座； D·往面缸内倒入洗涤灵水，用百洁布用力擦洗，直至光滑； E·用温水冲洗，直至光滑； 4）烤盘 A·将烤盘放入水池，注入温水； B·浸泡三分钟； C·用蘸有洗涤灵的百洁布用力擦洗烤盘表面； D·再用温水冲洗，直至光滑； 5）架子车 A·用蘸洗涤灵的百洁布涂抹架子车钢架； B·浸泡一分钟； C·用抹布蘸温水擦洗钢架，直至光滑； 6）展示台 A·先将展示台上商品取出； B·用于抹布将台面的杂质擦掉； C·用抹布蘸温水擦洗台面； D·将台面木板掀起； E·用干净的扫帚清扫展示台内壁； F·用抹布蘸水擦洗展示台内壁； G·用于抹布将展示台内壁擦干将台面木板盖上； 日常检查 生鲜加工中心生鲜主管将根据“生鲜部日常巡查程序”对该区域各项工作进行检查，对生鲜部主管检查过程中发现的各种问题；面包房的领班有责任进行整改。

# 第六节、生鲜食品包装规范
为规范生鲜食品的包装，以提供给顾客包装标准/统一的生鲜食品，特制定本规范。
1. 包装方法的分类
1）装销售商品(生肉、熟食、部分果蔬)的包装方法—A 2）散卖商品(部分水果、蔬菜)的包装方法—B
2. 包装方法A
1）将食品放入包装盒内，码放整齐 2）将该包装盒放在包装机上正中位置，拉出包装膜，将整盒包严拉出。 3）拉紧包装盒两边余出的膜，用劲贴在盒底部(包装后的商品要求包装膜表面绷紧，不能出现摺皱儿 4）将包装好的商品放在电子秤上，去皮称重，打印出价签。 5）将价签端正地贴在包装膜的右下角 6）将卫生防疫站检疫标签端正地贴在价签的正上方 (只限生肉制品) 7）不能将破损的价签、卫检签贴在商品包装上出售
3. 包装方法B
1）会员挑选好的商品己放入撕裂袋 2）用封口机将该袋封好口后，在电子秤上称重，打印出价签 3）将价签贴在包装袋的左下角今 ☆对于绿色叶类蔬菜，也可用封口胶带将蔬菜绑好后，直接称重，将价签贴在胶带上。 生鲜食品陈列、展示规范： 为规范生鲜食品的展示要求，以展示给顾客一个整洁的购物环境，调动顾客的购买欲，特制定本规范。
1. 商品的摆放要求
1）商品的摆放整齐笔直、外观干净。 2）发现包装破损、包装膜松懈的商品应立即返工，重新包装。(切记:注意包装日期) 3）同类商品摆放在一起，牛、羊肉制品应与猪肉制品分开摆放。 4）员工有责任保持展柜商品量的充足，出现空档应立即补充。 5）冷冻、冷藏柜的商品应保证价签位置的准确性。
2. 价签、POP的要求
1）所与的标价必须正确，保证每个商品都有标价。 2）每个POP必须用POP袋套住，特惠POP必须标出原价。 3）所有价格牌、POP必须干净、整齐一致。 4）在蔬菜陈列处，如有特惠商品，可用特惠POP标出，POP在原价钱牌下面。
3. 展柜的要求
1）展柜的照明应保持良好，灯具无损坏； 2）员工有责任随时保证展柜的清洁； 3）主管对展柜的温度应定时进行追踪记录 (见工作检查清单)，出现异常应立即通知设备组(化霜时间除外)
4. 果蔬的陈列要求
1）果蔬陈列要讲究颜色的搭配，如:红、黄、绿相间等； 2）促销时可运用堆头方式进行，通过量贩陈列吸引顾客； 3）堆头可通过垫高的方法达到丰满。 4）把毛利高、销售好的商品摆在堆头。 5）及时补货，覆盖陈列架，保持货架丰满。 6）做好先进先出。 7）变质的商品不能上架。 8）所有的菌类、菇类商品应放冷藏柜。
5. 熟食的陈列要求
A套餐柜 1)周一到周五，所有产品都用浅盘，这样看起来好看并可减少损耗。 2)周六、周日、节假日，小炒除了包类都可用深盘，其中要根据当天的营业额来灵活调整。 3)早班开店时水温要开到60摄氏度，没客人时把玻璃门关上。 4)有质量问题的商品不能出售。 5)价格牌要与电子称相符。 B熟展柜： 1)卤水产品只开灯即可，不能开温度。 2）其他商品开温度到60摄氏度。 3）所有商品价格牌与电子称一致。 4）所有商品在开门和交接班时要保持丰满，但切片的商品为了减少损耗，可在周一到周五减少一些，在下面垫上成块的商品可达到同样丰满的效果。 5）卤水要每15分钟翻动一次，并洒上香菜调色。 6）有质量问题的商品不能出售和陈列。
6. 肉类的陈列要求
1）开门前玻璃要干净。 2）肉类商品可做关联陈列，陈列柜上可放相应的调味品。 3）包装内有血水时要及时收回，重新打包。 4）变质商品坚决不能上货架。 5）肉类商品应每小时整理一次货架。 6）肉类陈列区域要保证地面无积水。
7. 水产的陈列要求
陈列原则：要求视觉饱满，颜色搭配和谐，装饰有新意，有正确的货架标签、POP，商品摆放有利顾客拿取，不易掉落，损耗少。 1）冰台： 1·1冰台的冰不能太多太高，冰面要有倾斜度，让远处的顾客一眼看到冰鲜鱼。 1·2冰鲜与的颜色要搭配和谐，装饰有新意，每天有不同的花样。 1·3冰鲜鱼要充分和冰接触，防止鱼因脱水而变质。 1·4陈列在冰台的包装商品，要高出冰面2/3，不能埋入冰内，而且要归类陈列;如:急冻海产品、包装活鲜类。 1·5三文鱼柳、鱼头、北极贝等即食产品要和冰鲜鱼间隔开，防止细菌感染。 1·6每种冰鲜鱼要有醒目的价格牌且一一对应。 1·7保持有干净的柠檬水，万便顾客洗手。 1·8冰鲜鱼陈列将要风干时，必须用盐冰水泡5分钟后再陈列，保证色泽光亮新鲜。 2）展示鱼池： 2·1淡水鱼和海水鱼耍分开陈列。 2·2鱼池内的鱼不能太少，保证每个品种在晚上8点前不少于陈列标准要求。 2·3不能有反肚的鱼、死虾、死蟹在池内。 2·4价格牌正确无误，每一个鱼池至少有一个价格牌。 2·5保持鱼池，海鲜陈列台干净，鱼池玻璃清洁明亮。 3）急冻展示柜 3·1陈列整齐有序，且饱满以方便顾客拿取。 3·2不能有包装破损，漏气的商品，或者商品结霜、结冰现象。 3·3有与商品相对应正确的价签。 生鲜部盘点程序： 本程序明确了盘点的程序和要求，以保证盘点数据的准确，从而提供正确的毛利报告。
1. 生鲜经理负责制定各部门目标毛利值。
2. 生鲜主管负责制定本部门盘点单、核查盘点数据，并将其与系统的差异数量作出报表交营运部财务部。
3. 电脑部录入员负责将相关数据录入系统，提交并打印出毛利报告。
4. 生鲜部采购、生鲜主管及生鲜经理负责查找实际毛利与目标毛利的差异原因。
5. 生鲜主管及生鲜经理负责制作“生鲜部损益表”。
6. 盘点员负责盘点数据的准确。
7. 盘点时间
1）生鲜商品的盘点定为每月一次(每月月底) 2）特殊规定生肉、熟食操作间盘点时间为下午17:00将开始，仅盘库里的商品。
8. 盘点程序
1）各操作间人员负责在盘点前一日制作出本操作间的盘点单(注意不要有遗漏)； 2）各操作间于盘点日按照作业指导书-盘点方法ABC三种方法认真盘点，填写盘点单，盘点员签字，当日负责盘点的主管核查后在"核查员"处签字。 3）电脑部录入员负责盘点单的录入。(注意应在确认盘点日所收货品已全部录入系统后进行)；打印盘点差异表。 4）主管负责完成盘点差异表的复核盘点。差异数量调整必需财务部与防损部签字复核。 5）电脑部录入员负责按照审核后的"调整数量"重新录入系统，并打印毛利报告交生鲜经理、店长及财务部。 6）如报告显示毛利异常，生鲜主管、生鲜经理及店长应立即查找原因， 对于毛利异常的情况应作出相应解释，报告交领导审批后复印存档财务部。 各操作间盘点方法： 为明确各操作间的盘点方法及要求，以保证盘点数据的准确性。 盘点方法的种类 方法A――适用于生肉司、熟食间的盘点 方法B――适用于包装材料的盘点 方法C――适用于果蔬司的盘点
1. 方法A
1）下午17:00开始盘点冷藏库及冷冻库内的单品 2）逐一称重单品，将重量填写在相应“盘点数量”栏 3）对无库存的单品应在其数量栏填写“0”，而不能空着不填 4）盘点员盘点完成后在“盘点员”一栏签字，将盘点单交主管核查。 5）盘点结束，清洁盘点区域，将所有库存单品摆放整齐，以备次日开店。
2. 方法B
1）于盘点日按照盘点单上所列单品的顺序进行清点 2）按照盘点单上所注单位进行认真清点(一定注意盘点单上每一单品所对应的清点单位是“箱”、“个”等) 3）对无库存的单品应在其数量栏填写“0”，而不能空着不填 4）盘点员盘点完成后在“盘点员”一栏签字，将盘点单交主管核查。 5）盘点结束，清洁盘点区域，将所有库存单品摆放整齐
3. 方法C
1）晚上19:00将台面补满后开始盘点库里的单品 2）逐一称重单品，将重量填写在相应“盘点数量”栏 3）对无库存的单品应在其数量栏填写“0”，而不能空着不填 4）盘点员盘点完成后在“盘点员”一栏签字，将盘点单交主管核查。 5）当日关店后或次日开店前盘点台面上的剩余商品，以“+”的方式补记入盘点单相应数量栏(如一单品库内存货为2·646KG、台面上剩余存货重量为1·254KG，则记录为“2·646+1·254”即可) 6）盘点员完成后交主管核查。 7）盘点结束，清洁盘点区域。

生鲜日常管理

# 第一节、生鲜部日常巡查程序
A、生鲜主管负责整个生鲜区日常巡查工作及人员管理。 B、生鲜经理负责对日常巡查中的生鲜管理检查和生鲜商品的品质控制。
1. 检查频次和内容
1）生鲜商品日常巡查的频次规定为每日四次，具体的巡查时间安排为： 1）开店检查 2）营业期间不定时的检查(两次/天) 3）关店检查
2. 每日所进行的检查应包括以下几项工作：
1）商品质量及展示情况 2）环境卫生 3）设备设施状况 4）人员卫生及服务质量
3. 生鲜加工中心主管将针对不同的检查范围及检查时间制定详细的“生鲜部日常巡查清单”，明确不同检查范围及检查时司所应巡查和确认的内容。
4生鲜主管制定检查清单应按质量体系文件控制的要求进行控制。
2. 生鲜部日常巡查
1）生鲜主管及生鲜经理依据生鲜商品工作检查清单以及各操作工作规范进行开店前、营业期间及关店后的检查，每日的开店前检查应在正式开店前完成；每天的营业期间检查应为两次;每日关店后的检查应在关店后进行。 2）生鲜部主管的检查结果将有如下三种情况： a合格 (所检查的每项活动符合相应操作规范)。 b不合格，可当场纠正(检查中发现不符合规范的操作，但现场可立即纠正)。 c不合格，需采取纠正和预防措施 (检查过程中发现不合格的情况，重复发生或当场无法纠正)，应按照程序登记上报。 3）主管检查后应将存在的问题填写在检查单的相应栏(关店时发现的问题请记录在相应操作间的“备注”栏)并在“检查人签字”一栏签字。 4）生鲜主管检查后将检查单钉在店长办公室的提示板上；店长跟踪解决。

# 第二节、生鲜商品损耗控制规范：本程序规定了在生鲜加工及门店各生鲜区域对生鲜商品损耗的控制，以确保生鲜生鲜损耗的有效控制，降低损耗，提升毛利额。
1. 孤儿商品：由于顾客临时改变决定，不购买某些商品而随手放下，但没有归回原位的商品。
2. 称重商品：某些散装的商品，如杂粮、糖果等，需要用电子称来称重以计算销售单位的商品，叫做称重商品。
3. 收货时的生鲜损耗控制
1）严格按照收货标准收货 2）按照实收数量填写收货单 3）称重商品要去水。
4. 门店的生鲜损耗控制
1）门店应加强生鲜商品的巡查与维护，每日四次，具体的巡查时间安排为： A·开店检查 B·营业期间不定时的检查 (两次/天) C·关店检查 2）每日所进行的检查应包括以下几项工作： A·商品质量及展示情况，发现损耗，及时处理。 B·环境卫生，保峙良好的卫生状况。 C·设备设施状况，保持设备良好的运转，冷冻、冷藏设备保持正常温度。 D·人员卫生及服务质量
5. 先进先出原则：
理货员在理货、补货时要严格按照先进先出的原则，把原来的生鲜商品往外靠
6. 变价：
1）如果超过晚上20:00仍有大量的生鲜商品库存，生鲜经理应积极安排包括叫卖等形式的促销。 2）门店生鲜商品实行实时的店内变价，每日晚上20:00要做当天生鲜商品的折价处理或买一赠一，以保证门店的生鲜商品日日新鲜。 3）变价后及时跟进价格牌、POP和标签的更改。 4）生鲜经理要严格控制生鲜降价和买赠行为，生鲜的毛利率是生鲜经理的考核指标。
7. 称重商品：
门店理货员在电子称上进行称重商品的称重时，要严格按照商品名称和单价打价，严禁私打价格，或者故意错价。
8. 孤儿商品：
理货员进场理货，发现生鲜商品孤儿，应在第一时间内归位，防止需冷藏的商品和保质期过短的商品因在外停留时间过长而变质。
9. 扫描：
收银员扫描时，要正确扫描商品码，如商品编码脱落或不清晰，要让店内生鲜理货员重新确认正确的编码
10. 保质期的管理：
1）对于日配、糕点、面包等标注保质期的包装商品，要严格遵循先进先出原则，同时每日检查商品的保质期，确保商品的安全保持管理。 2）每次巡检中发现有超过保质期仍在销售的商品，将对该门店的生鲜理货员、生鲜主管进行处罚。加强生鲜加工区域与门店销售区域的巡检，发现问题，立即纠正。 3）严格控制每日最后一次加工的产量，以避免应过量造成损耗。 4）严格控制耗材的使用。 5）加强对员工的培训，培养全员降损的概念。
11. 防损部的生鲜损耗控制
1）防损部加强防盗管理，严禁员工偷吃偷拿，一旦发现，立即开除。 2）防损部加强对生鲜损耗严重的商品的监控，提出纠正防损措施。
